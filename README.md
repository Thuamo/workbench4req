# 需求智能工作台

可运行的中文 Web 工作台，覆盖用户认证、三级权限、文档版本、多人会签、知识发布、澄清台账、需求关系和 LangGraph 工作流。数据来自数据库与用户上传文件；未配置模型时明确返回配置错误。

## 立即使用

当前本机入口：<http://localhost:3000>。首次使用先初始化管理员，再通过页面注册成员或由管理员创建审核员。源码不含固定管理员密码。

Windows 如遇“禁止运行脚本”，在项目根目录运行 `./start-local.cmd`；它只为本次启动设置执行策略，不修改系统长期策略。停止和重启可用 `./stop-local.cmd`、`./restart-local.cmd`。

在项目根目录运行：

```powershell
./scripts/setup.ps1
./scripts/install-frontend.ps1
./scripts/check-frontend.ps1
./scripts/start-local.ps1
```

本机依赖已经安装，服务已经启动。无需再次执行安装或启动。首次管理员初始化：

```powershell
$env:PYTHONPATH = "$PWD/backend"
./.venv/Scripts/python.exe -m app.cli init-admin --username your_admin
```

命令交互读取并确认密码，至少 6 位。管理员创建后禁止再次初始化；在“系统管理”中维护角色、模型、标签与度量规则。

## 已实现

- 注册、登录、修改密码、HTTP-only 会话、CSRF、服务端资源授权、管理员审计。
- 六类知识库、目录、原始文件下载、草稿编辑、历史修订、差异、恢复为新草稿。
- 私有暂存与正式检索分离；并行会签全部通过后创建唯一发布任务，任一退回取消剩余待办。
- 文件、知识修订、索引、快照各自版本化；提交内容和历史决定不可修改；新索引完成后原子切换当前版本。
- 中文 BM25、可选真实 embedding、RRF 重排、版本/快照/历史时间检索和引用定位。
- Excel 台账支持按需求编号预览增量导入、撤销导入批次、逐格和全部字段编辑、修改历史、过滤排序分页、批量状态及原字段导出。
- 需求标签、可解释度量、候选/确认关系图；AI 候选人工选择回存。
- 四个内置技能、个人技能编辑及 ZIP/.skill/SKILL.md/JSON 包导入导出、公共发布申请、技能版本、Slash 调用、多轮流式聊天；业务下拉框支持搜索匹配。
- Supervisor、Knowledge、Requirement、Clarification、Impact、Document、Review 七种 LangGraph 节点；按技能生成正文后进入人工/AI编辑，暂存编辑进度或确认版本进入需求列表。提纲确认支持100项和持久化恢复，候选确认统一在需求列表处理，保存版本后继续人工会签。
- Word 导出应用样例字体、标题、行距、页边距，保留可解析表格和来源版本；草稿明确标记。

## 当前操作动线

从“开启新工作”选择需求登记、文档生成、知识问答或继续处理。业务需求详情集中展示资料、版本、候选和审核；生成任务自动带入需求资料。正文仍按“技能生成 → 人工/AI编辑 → 确认版本 → 需求列表”处理，确认后可从详情直接提交会签。首页恢复待办，编辑支持自动暂存、离开保护和刷新恢复，通知及页面地址可定位业务对象。

数据库新增迁移0003区分业务需求、工作草稿和结构化明细；升级前本地备份保存在data/backups。

## 验收边界

已通过本地 SQLite API 测试、迁移与数据库约束检查、前端严格类型与生产构建，并使用真实附件完成 6 份文档和 290 行台账的隔离测试。业务原件的测试会签不代表真实业务审批，也没有自动发布到本机正式库。

本机已于 2026-10-26 配置 `qwen3.8-max`，真实普通响应、JSON 输出和流式响应均通过连接验证，密钥在本地数据库加密保存。业务文档生成质量及 embedding 仍需分别验收；模型协议测试替身只验证调度、暂停恢复和引用校验。当前环境没有 Docker，PostgreSQL/pgvector 和容器部署尚未运行验收。图片 OCR、复杂合并单元格及原件自动编号的完整还原需要人工核对。

较大规模的数据库端 ANN 检索优化、S3 存储适配、自动依据知识变化发起影响检查、完整业务领域实体治理和可上传替换的 Word 模板引擎尚未实现。

## 文档

服务启动后可在 [运行时 API 文档](http://127.0.0.1:8000/docs) 查看接口。项目说明文档保存在本地 `docs/`。
